# Security

Report vulnerabilities through the form at **https://www.surge.credit/security** (Report a
vulnerability). If the form does not work for you, email developer@surge.build. Do not open a
public issue.

Include what you found, the affected file or contract, and the steps to reproduce.

In scope: this engine and `contracts/BatchBuyer.sol`. Issues in the Surge Credit protocol contracts
or signer network go through the same form.
